Importar Funcionários via CSV

Importar funcionários em lote utilizando arquivo csv.


Orientações:
  • O arquivo CSV deve conter colunas: nome, matricula, cargo, cpf, empresa_id, secretaria, setor, status_contratual, observacao
  • No mínimo, os campos nome, matricula, cargo, cpf, empresa_id, secretaria são obrigatórios
  • Atenção com o CPF: Para evitar a perda de zeros à esquerda (ex: 012.345.678-90), formate a coluna 'cpf' como "Texto" no seu editor de planilhas (Excel, Google Sheets, etc.) antes de salvar como CSV.
  • Baixe o arquivo modelo para facilitar a importação.
